# API Reference

## Webhook

**POST** `/webhook`

Основной эндпоинт для приёма событий от MAX.

### Формат запроса

```json
{
  "update_type": "bot_started",
  "chat_id": 1234567890,
  "user": {
    "user_id": 1234567890,
    "name": "Иван",
    "username": "ivan_petrov"
  },
  "payload": "vip"
}
```

### Обрабатываемые события

| `update_type` | Описание |
|---------------|----------|
| `bot_started` | Пользователь запустил бота (включая deep-ссылки с `?start=`) |
| `message_created` | Новое сообщение |
| `message_callback` | Нажатие на inline-кнопку |

### Ответ

Всегда `200 OK`, даже при ошибке в обработчике:

```json
{ "ok": true }
```

### Команды бота

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/start` | Все | Приветственное сообщение |
| `/setlink <key> <url> <msg>` | Админ | Создать связку (сохраняет `creator_id`) |
| `/dellink <key>` | Админ | Запрос на удаление связки (с подтверждением). Админы могут удалить любую, создатель — только свою |
| `/links [N]` | Все | Постраничный список связок (20 шт): админ — все, создатель — только свои. `N` — номер страницы |
| `/link <key>` | Все | Карточка связки: текст сообщения, ссылка, диплинк; кнопки «Удалить», «Посмотреть». Создатель — только свои |
| `/users` | Админ | Количество пользователей |
| `<ключ>` | Все | Получить ссылку по ключу |

Каждая связка (`link:<key>`) хранит поле `creator_id` — ID пользователя, создавшего ключ. Для связок, созданных до введения этого поля, миграция назначает первого админа из `ADMIN_IDS`.

### Inline-кнопки (callback-колбэки)

| Колбэк | Где появляется | Описание |
|--------|----------------|----------|
| `del:<key>` | Кнопка `🗑 Удалить` в карточке | Показывает диалог подтверждения удаления |
| `confirm_del:<key>` | Кнопка `✅ Да, удалить` в диалоге | Удаляет связку; после — «🔙 К списку» |
| `links_page:<n>` | Кнопки `⬅️` / `➡️` в списке | Переход на страницу списка |
| `link_preview:<key>` | Кнопка `👁 Посмотреть` в карточке | Отправляет сообщение связки как видит пользователь |
| `back` | Кнопка `🔙 Назад` (только админ) | Возвращает в главное меню админа; не-админ получает подсказку |
| `links` | Кнопка `❌ Нет` в диалоге удаления, «🔙 К списку», «🔙 Назад» в карточке | Возвращает к списку связок |
| `create` | Кнопка `➕ Создать` в главном меню | Показывает подсказку `/setlink` |
| `users` | Кнопка `👥 Пользователи` | Показывает количество пользователей |
| `broadcast` | Кнопка `📨 Рассылка` | Показывает заглушку |

### Навигация

Раздел «Связки»: главное меню → список (постранично, кнопки `⬅️`/`➡️`, «Назад» только у админа) → карточка через `/link <key>` или ввод команды. Карточка: текст сообщения, ссылка, диплинк, кнопки «🗑 Удалить», «👁 Посмотреть», «🔙 Назад» (к списку). У создателей (не-админов) список и карточки — только для своих связок.

### Обработка событий

В дополнение к `message_created`, бот обрабатывает `message_callback` для inline-кнопок и `bot_started` для глубоких ссылок.

## Setup Webhook

**GET** `/setup-webhook?secret=ВАШ_SECRET`

Регистрирует webhook в MAX API. Вызвать один раз после деплоя.

### Параметры

| Параметр | Описание |
|----------|----------|
| `secret` | Секретный ключ из `SETUP_SECRET` |

### Ответ

```json
{
  "webhookUrl": "https://.../webhook",
  "result": { "success": true }
}
```

## Коды ответов

| Код | Значение |
|-----|----------|
| 200 | Успех |
| 400 | Неверный JSON |
| 403 | Неверный secret |
