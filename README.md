# LinkPost Bot

> Бот для мессенджера MAX: создавайте связки «ключ → ссылка на канал» и делитесь ими через deep-ссылки.

LinkPost — простой бот на Hono.js, развёрнутый на Vercel Edge. Администраторы создают ключи, привязанные к ссылкам на каналы. Пользователи отправляют боту ключ и получают ссылку с кнопкой перехода.

## Быстрый старт

```bash
git clone <repo>
cd linkpost-bot
npm install
vercel env pull
vercel dev
```

## Возможности

- **Управление связками** — создание, удаление, просмотр ключ-ссылка-сообщение
- **Deep-ссылки** — `https://max.ru/<bot>?start=<key>` для быстрого распространения
- **Учёт пользователей** — автоматическое сохранение информации о пользователях
- **Inline-кнопки** — ссылки с кнопкой перехода в канал
- **Администрирование** — команды в чате с разграничением прав

## Пример

```
/start → Привет, Админ! В базе 12 пользователей.
/setlink vip https://max.ru/channel/xxx Добро пожаловать! 🎉
→ ✅ Связка сохранена!
/links → список связок (постранично)
/link vip → карточка связки с кнопками «Удалить» и «Посмотреть»
```

Пользователь отправляет ключ `vip` и получает ссылку на канал.
