# LinkPost Bot

## Обзор

LinkPost — это бот для мессенджера MAX, развёрнутый на Vercel Edge. Позволяет администраторам создавать связки «ключ → ссылка на канал» и делиться ими через deep-ссылки. Пользователь отправляет боту ключ и получает ссылку на целевой канал с приветственным сообщением.

## Основные возможности

- Управление связками ключ-ссылка (добавление, удаление, просмотр)
- Deep-ссылки вида `https://max.ru/<bot>?start=<key>` для быстрого распространения
- Автоматическое сохранение информации о пользователях
- Поддержка inline-кнопок со ссылками
- Администрирование через команды в чате
- Разграничение прав (администратор / обычный пользователь)

## Технологический стек

- **Язык программирования:** JavaScript (ES Modules)
- **Фреймворк:** Hono.js
- **База данных:** Vercel KV (Redis)
- **Мессенджер API:** MAX Bot API (@maxhub/max-bot-api)
- **Развёртывание:** Vercel Edge Runtime
- **HTTP-клиент:** Native fetch

## Архитектурные заметки

- Приложение построено как набор Hono-роутов, обрабатываемых на Edge
- MAX Bot API используется через тонкую обёртку на `fetch` (без SDK)
- Vercel KV используется для хранения связок и пользователей
- Webhook регистрируется однократно через эндпоинт `/setup-webhook`
- Аутентификация бота — через заголовок `Authorization: <BOT_TOKEN>`

## Нетребовательные к производительности характеристики

- **Логирование:** `console.error` для ошибок, без внешнего логгера
- **Обработка ошибок:** try/catch с возвратом 200 OK (MAX не ретраит)
- **Безопасность:** токен бота через переменные окружения, секрет для setup-webhook
