# Code review: необработанный callback, дублирование форматирования, пропущенные тесты

**Date:** 2026-06-08 03:14
**Files:** api/index.js, test/handler.test.js
**Severity:** low

## Problem

После code review остались 4 незакрытых замечания:

1. Неизвестный `cb.payload` молча игнорировался — пользователь не получал обратной связи при нажатии устаревшей inline-кнопки.
2. Логика форматирования списка связок и построения клавиатуры была дублирована между `/links` (handleMessage) и `links` (handleCallbackQuery). Отличались только полем `💬 message`.
3. Не было теста на callback `broadcast` — заглушка оставалась непроверенной.
4. Не было теста на ключ с двоеточием (`key:sub`) — граничный случай для `slice('confirm_del:'.length)`.

## Root Cause

1. В `handleCallbackQuery` после цепочки `if` не было else-ветки для неизвестного payload — язык JS возвращает `undefined`, MAX не получает ответа.
2. При добавлении второй точки использования списка связок (callback `links`) разработчик скопировал код из `/links` вместо извлечения общей функции.
3. Тесты писались только под новые callback-пути, broadcast остался «старой» заглушкой без покрытия.
4. Тест-дизайн не учитывал ключи со спецсимволами — предполагалось, что ключи всегда простые.

## Solution

1. Добавлен `console.warn('[API] handleCallbackQuery: неизвестный payload', cb.payload)` в конец `handleCallbackQuery`.
2. Извлечены две helper-функции:
   - `formatLinksList(links, showMessage = false)` — форматирует список в строку
   - `buildLinksKeyboard(links)` — строит массив кнопок с `🗑 key` и `🔙 Назад`
   Оба места переписаны через них.
3. Добавлен тест `should show broadcast placeholder with back button`.
4. Добавлен тест `should handle confirm_del: with colon in key name`.

## Prevention

- При добавлении нового callback всегда проверять, что все неизвестные payload логируются.
- При появлении второй точки использования одинаковой логики отображения — сразу выделять helper.
- Тестировать не только новые сценарии, но и существующие заглушки/старые callback'и при их изменении.
- Включать в тест-дизайн ключи со спецсимволами (двоеточие, пробел), если они передаются через slice по префиксу.
